# English recordings (raw)

Carina's original English voice recordings go here, exactly as recorded (with beeps and "again" retakes).
Name each file with its code, e.g. `R07 EN.m4a`, `R03 EN Breathe in.m4a`.

These are the raw files. They are cleaned with `tools/audio/clean_recordings.py` (see `docs/AUDIO.md`)
and the cleaned versions go into the app separately.
